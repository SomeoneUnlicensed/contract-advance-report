# Аванс по договору

Скрипт строит отчёт по расчётам с подрядчиками на дату: по каждой работе — цена, выплачено и остаток, по каждому договору — итоги.

## Запуск

Python 3.10+, зависимостей нет:

```sh
python report.py --date 2026-11-10
python -m unittest
```

Данные читаются из `data/` рядом со скриптом, другую выгрузку можно передать через `--data ПАПКА`. Формат файлов — [data/FORMAT.md](data/FORMAT.md).
